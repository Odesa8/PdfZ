# PDF Reader

Проста офлайн PDF-читалка для Android без реклами та аналітики.

## Можливості
- відкриття PDF через системний вибір файлів;
- відкриття PDF з інших застосунків;
- сторінки вперед/назад;
- pinch-to-zoom та перетягування;
- без мережевих дозволів, реклами, SDK аналітики чи трекерів.

## Збірка
Проєкт налаштований на Android Gradle Plugin 9.4.0 і Gradle 9.6.0.
GitHub Actions workflow `.github/workflows/build-apk.yml` автоматично збирає debug APK та публікує його як artifact.
